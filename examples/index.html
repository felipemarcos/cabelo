cabelo examples

Run npm start to rebuild the library on change while you browse these.

  • Timeline: nested tweens, colors, edge class names and events.
  • Keyframes: several positions and values in a single tween.
  • Easing: the built-in easing curves side by side.
  • Relative positions: tweens tied to where an element is on the page.
  • Reveal on scroll: hooks that toggle a class on each element.
  • Properties: CSS variables, counters, SVG attributes and plain objects.
  • Pinned section: a sticky section that scrolls sideways, using trigger.
  • Horizontal scroll: a scroll container on the x axis.
